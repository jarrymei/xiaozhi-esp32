# 独立硬件实验记录

每个实验使用独立文件夹，分别保存接线、原理、代码入口和排查方法；机器人选型、采购及机械设计仍保留在`docs/project/`。

后续实验文档继续采用“两位序号-实验名称”的独立文件夹，按实验开展先后顺序递增编号，例如 `05-实验名称`。同一实验的补充记录更新到原文件夹，不因更新日期变化重新编号；新增或重命名文件夹时同步更新文档索引和相关链接。现有记录的整理日期可能相同，编号以实际实验开展顺序为准。
