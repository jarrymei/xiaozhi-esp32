## 当前实验接线与控制资源

以下为当前源码配置及已完成实验的接法；实际改线后需同步更新。

| 功能 | 引脚 / 资源 | 连接说明 |
|---|---|---|
| LED | GPIO18；LEDC 定时器 2、通道 2；5 kHz、10 位 | GPIO18 → 限流电阻 → LED 正极；LED 负极 → GND |
| SG90 信号 | GPIO17；LEDC 定时器 3、通道 3；50 Hz、14 位 | GPIO17 → 舵机信号线，常见橙/黄色 |
| SG90 电源 | 外部稳压 5 V | 电源正极 → 舵机红线；不连接开发板 5V/3V3 引脚 |
| 舵机共地 | 电源负极、舵机负极、开发板 GND | 三者连接在一起；舵机负极常见棕/黑色 |
| 麦克风 I2S | WS=4、SCK=5、DIN=6 | 当前采用单工音频接线配置 |
| 扬声器功放 I2S | DOUT=7、BCLK=15、LRCK=16 | 接 MAX98357 模块 |
| OLED I2C | SDA=41、SCL=42 | 128×32 配置 |
| 开发板 BOOT | GPIO0 | 当前已有按键实验代码 |
| 配置中的其他按钮 | 触摸=47、音量加=40、音量减=39 | 源码已配置，不等于所有实物均已连接 |
| 板载灯配置 | GPIO48 | 依主力板实际电路核对灯的类型 |
| 编译烧录与调试 | 芯片目标 esp32s3；ESP-IDF v5.5.6 | UART 用于串口，原生 USB 用于内置 JTAG；端口号可能变化 |

当前舵机按 500～2500 μs 映射估算角度，软件允许 10～170 度，摇头动作使用 60～120 度。此处是控制参数记录，不保证每只 SG90 的实际机械角度与之严格一致。
