核查日期：2026-10-26。状态：已选定入门复刻路线，形成采购规格清单；尚未下单、下载完整PCB工程或完成外壳实物配合验证。

后续核查见[OTTO电子包与外壳尺寸核查](./OTTO电子包与外壳尺寸核查.md)：已定位作者购买入口并测量固定版STL，但当前在售主板实物版号与尺寸未公开确认。原版目录没有独立命名的Otto_body模型，本文“身体”不是要求另买其他版本body。

## 1. 选型结论

选用 **OttoRobot V1.1 非摄像头电子方案 + Verdure EMO 原版静态耳机外壳，先做四舵机腿脚基础版**。

- 主控仍为 ESP32-S3 N16R8，不换到Linux平台。
- 第一阶段4颗180度位置舵机：左右腿、左右脚。先站立、摇摆和慢速行走。
- 手臂作为下一阶段，可扩展为6颗舵机；当前不承诺现有非摄像头引脚配置能够直接支持两只手。
- 外形选原版 `verdure-emo`，不选带活动耳朵的 `verdure-emo-v2`，减少执行器和外壳零件。
- 面部使用匹配主板的1.54英寸240×240 ST7789 SPI屏。
- 成品推荐买已焊接测试的非摄像头主板，优先和屏幕、电池、音频件配套采购，避免第一次复刻就处理裸模组与细间距器件焊接。
- 保留当前面包板、小智v2.2.4/ESP-IDF v5.5.6开发环境。它是学习和电路验证平台，不因复刻而拆掉。

这不是“已经验证所有文件完全配套的一键下单包”。立创项目网页返回403，本次无法核对Gerber、PCB修订号及完整电源原理图；外壳README可读，但未完成STL尺寸测量。下文将这类不确定性单独标注。

## 3. 现有物料怎么复用

| 现有物料 | 能否复用 | 决定与限制 |
|---|---|---|
| 44引脚ESP32-S3 N16R8开发板 | 开发验证可复用；原版成品不直接复用 | BOM里的WROOM是焊接模组，不是44针开发板。不可假定能插进专用PCB或塞进外壳；不从现板拆焊模组 |
| 现有SG90位置舵机1颗 | 有条件复用为第4颗 | 检查尺寸、摇臂、供电、左右行程、齿隙与归中重复性；“90～180度”选项不足以确认具体行程。通过后基础版再买3颗；不通过则买4颗统一规格，旧舵机留作实验 |
| 0.91寸128×32 SSD1306 OLED | 保留实验，不用于标准EMO脸部 | 与1.54寸240×240 SPI LCD的尺寸、接口、驱动均不同 |
| INMP441模块 | 电路验证可复用；装机有条件 | 作者BOM说明模块方案可用INMP441；但模块并不等于可焊在ICS43434裸芯片焊盘上，成品优先用板载麦克风 |
| MAX98357模块 | 电路验证可复用；装机有条件 | 不保证模块可替换PCB上的裸芯片和外围；成品优先用板载功放 |
| 现有扬声器 | 待尺寸/阻抗/接口核对 | 目标为28mm级，参考2828、4Ω3W；未确认现有参数前不算可直接复用 |
| 5V USB充电器 | 有条件复用为配套主板充电输入 | 核对铭牌及主板USB输入规格；不把单舵机供电经验扩展为四/六舵机电源保证 |
| USB数据线、电脑、ESP-IDF环境 | 可复用 | 学习环境保持不动；新作者主线可能需并行安装其他IDF版本 |
| 面包板、杜邦线、鳄鱼夹线 | 可复用为台架测试 | 成品用固定端子和可靠线束，多舵机电源不经过面包板细电源轨 |
| LED、电阻、按键包 | 继续学习备用 | 普通轻触按键不保证与外壳开孔、专用板高度一致 |
| 万用表 | 如已到货则复用 | 先核对当前是否持有，不能从购物车记录推定到货 |

结论：复用最多的是学习平台和开发能力；原版紧凑成品可能需要专用主板。这不等于放弃ESP32技术路线。

### 推荐采购形态

询价“非摄像头主板电子包（含匹配屏幕、电池和喇叭）+ 原版EMO打印件包 + 4颗匹配位置舵机”。明确是否可减去已有且验证通过的舵机。若只有6舵机套装，手臂可暂不安装，但需要先确认所售主板如何解决手臂与LCD的GPIO复用问题。

先比较同一家配套电子包与散件成本，不报未经核实的现价；不因节省几颗模块而增加大量改板和外壳适配工作。

### 现在不买

- 裸ESP32模组、MAX98357裸芯片、ICS43434裸芯片：推荐的已焊接电子包应已包含，不重复买。
- 摄像头、活动耳朵4.3g舵机、Linux主控、IMU、PCA9685：当前基础版没有必须购买的依据。
- 双轴云台：这是前一个固定头部方案的物料，不是本次Otto腿脚结构必需品。
- 新LED、电阻包、通用杜邦线大包：先用现有库存。
- 2S/7.4V电池：不能替代本方案1S电池直接插板。

## 5. 手臂扩展为何暂缓

在作者当前config.h以及本地Otto配置中，非摄像头版本的right_hand_pin与display_cs_pin均为GPIO12。仅靠README无法判断某块PCB是否把LCD片选固定处理、使用特定屏幕，或需要源码改线。不能声称“六颗舵机接上就能用”。

后续增加2颗位置舵机与手臂打印件之前，核对所选板卡原理图和屏幕CS线路，并决定使用板卡配套固件，或调整引脚实现。先买六颗并不能解决这个问题。

## 6. 固件与现有代码的关系

- 首次成品点亮优先使用主板供方确认过的匹配固件。下载页当前v2.5.3仅是候选，不把它与V1.1硬件自动等同。
- 自定义学习继续在当前工程进行。现有上游v2.2.4已包含otto-robot代码，但旧版与作者主线存在差别；没有验证编译与硬件前，不宣称可以直接替换。
- 作者当前编译指南推荐IDF v6.0.2，而组件清单最低要求仍是>=5.5.2。最低依赖条件不等于所有组合均实测通过。暂不升级、覆盖当前工具链。
- 切换面包板到Otto固件需要核对全部引脚和电源。GPIO17/18原来是独立舵机/LED实验引脚，在Otto中是腿脚信号，不能带着旧接线直接刷现成固件。
- 现有自定义摇头队列与Otto动作库不能同时拥有同一舵机输出；未来集成时统一动作入口和停止语义。

## 8. 实施验收顺序

1. 核对所售版本及配套关系，补齐BOM，冻结具体文件和板号。
2. 电子包上电检查、屏幕与语音验证，先不安装机械负载。
3. 逐颗测试舵机方向和中位，做标记；按教程归中后再装摇臂。
4. 组装四舵机机身，悬空检查限位和线束。
5. 地面站立、低幅摇摆、慢速行走，观察重启、抖动、发热及卡线。
6. 学习源码并接入自定义MCP和日志，最后评估手臂扩展。
