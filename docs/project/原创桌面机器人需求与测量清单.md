- 原OttoRobot V1.1电子包与Verdure EMO外壳采购方案保留作历史参考，不继续作为当前采购依据。

## 用户提供的商品尺寸资料

以下为商品图标注或据标注换算的数据，均非实物测量；用于占位与试件准备，不作为精确孔位依据。

- [ESP32-S3商品尺寸图](./references/ESP32-S3商品尺寸图.png)：板体约57.15×27.94 mm，含图中右侧突出部分总长约63.39 mm（2495.63 mil）；两排针中心距25.40 mm，每排首末针中心跨度53.34 mm。总高度、插头空间和与现有实物的一致性仍待核对；排针孔不作为空闲安装孔。
- [SG90商品参数图](./references/SG90商品参数图.png)：宽标12 mm，另两向标32 mm，但包含结构边界不明确；图注尺寸误差0.5～1 mm。缺少安装孔距、孔径、轴心位置及摇臂配合尺寸，不能据此直接输出最终舵机座。
- SG90图标工作电压3.5～6 V、线长约25 cm；红线电源、棕线地、橙线信号。图标100 mA不能作为启动、负载或堵转电流，也不能按四颗400 mA配置电源。
- 此前40×20×39 mm舵机图与SG90记录不符，排除为本轮SG90结构设计依据。

下一步先按四舵机腿脚机构选择执行器，不再以测出现有SG90孔距作为前置条件。候选舵机需有完整尺寸图，明确本体、安装耳、孔距、轴心、摇臂和配套螺丝；同时核对工作电压、重量、扭矩测试条件和电流资料。模型按候选资料制作单座试件，收到实物后验证配合。开发板、扬声器采用留余量的开放式固定，暂不制作紧配合外壳。

## 测量约定

- 全部尺寸使用毫米；重量使用克。记录工具及读数精度，不补写无法测出的数字。
- 零件正面朝向观察者，标明照片中的左、右、上、下；安装平面左下角可作为该零件局部原点。
- 孔位记录孔中心到基准边的距离；孔径、孔中心距与边到边距离分开记录。
- 外形尺寸、安装尺寸和活动/插拔空间分开记录。排针、焊点、连接器、线束均计入占用空间。
- 游标卡尺适合孔位与配合尺寸；只有直尺时可先做布局草案，不能据此冻结精密配合。
- 不确定项填写“待测”。型号或商家标称尺寸单独列为参考，不能冒充实测。
- 每种零件拍正面、背面、侧面和带尺照片，并给零件编号；后续四颗舵机逐颗编号。

## 舵机活动范围记录

现有程序启动输出1500 μs，按估算角度90°记录；500～2500 μs线性映射，软件限制10～170°。这些都不是实测机械限位。

1. 先拆除腿脚负载，让摇臂周围留出空间，标记中位方向。
2. 从中位小幅调整，记录指令角度、实际偏转方向和大致角度；不要直接以10°/170°寻找机械端点。
3. 若出现顶住、异响或异常发热，立即断开舵机电源；现有“停止动作”仍维持PWM，不能代替断电。
4. 记录无负载安全区间、归中重复性、齿隙以及测量方法；安装机构后重新缩小并验证允许区间。

不以手掰输出轴或持续堵转测量能力。首轮不要求测堵转电流或承重极限。

## 从数据到样机的顺序

1. 完成需求选择和首轮实测，先做真实尺寸的零件占位与布局草案。
2. 确定四个关节的轴向、舵机本体/摇臂固定关系、脚底支撑范围和线束路径；先验证单个关节。
3. 建立参数化模型，明确基准尺寸、装配间隙、壁厚、紧固方式；输出STEP/STL及装配图。
4. 先打印舵机座、屏幕框等局部试件，检查配合，再打印整机。
5. 模块接线完成机械样机，依次验证悬空运动、站立、低幅动作、慢走；记录倾倒、卡线、松动和供电/音频问题。
6. 机械及电气验证后冻结接口，再设计扩展PCB、原理图、接线图、BOM与生产文件。

模型检查可发现干涉与尺寸矛盾，不能证明舵机承重、打印配合、稳定性、供电压降或音频抗干扰已通过。

## 当前代码基线核对

- `servo_controller.h`：单格队列、独立任务；停止保持最后指令；启动自动输出中位。
- 舵机LEDC定时器3/通道3为类内固定值，不能简单创建四个实例来控制四颗舵机；多轴阶段需要统一分配通道与动作控制。
- `compact_wifi_board.cc`：GPIO17实例化舵机；LED使用GPIO18。
- `config.h`：音频和I2C屏幕引脚与现有接线记录相符，屏幕高度由编译配置选择。
- 当前`sdkconfig`选择`CONFIG_COMPILER_OPTIMIZATION_SIZE=y`，仍是体积优化（-Os）；未选择调试优化。本轮未重新编译，不能据此确认此前烧入固件的编译参数。
- `.vscode/launch.json`已有`monitor gdb breakpoint_override hard`。
- 后续机械建模单独放在`mechanical/a1`，未修改控制代码、编译配置或接线。
