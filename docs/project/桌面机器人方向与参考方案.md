## 阶段与验收

1. 两轴实体：轻量屏幕头部、固定底座、俯仰与左右转动；完成零位、方向和机械限位校准。
2. 陪伴互动：待机眨眼、聆听/说话表情、点头、摇头、打招呼；动作中正常对话，可取消动作。
3. 感知：先加一种触摸或姿态传感器；用事件触发表情和动作，避免重复触发造成指令拥堵。
4. 四足预研：确定8或12关节结构、完整尺寸和BOM；先装配单腿，验证负载与运动范围。
5. 四足执行：悬空校准 → 地面站立 → 原地抬脚 → 慢速爬行 → 接入小智动作工具。初期在地面测试，不依赖云端停止或未经验证的桌沿检测。

## 硬件与采购原则

- 现有0.91寸128×32屏可以先用；参考项目的128×64或彩屏不能直接认为固件、安装孔和外壳兼容。
- 两轴阶段：先确定支架后选匹配舵机。已有SG90可做轻载实验；若选DeskEmoji的MG90S支架与重载结构，应按实际尺寸和负载匹配，不能只按“9g舵机”判断。
- 本轮候选物料：第二颗位置舵机、匹配两轴支架与固定底座、延长线、电源分配端子、开关、线材和紧固件。
- 四足采购暂缓：Sesame官方BOM指定8颗180度MG90S；已有1颗SG90不直接算作可替换的腿部执行器。
- Sesame文档列出5V/3A供电要求；这只是该设计的参考条件，不是任意8舵机系统的通用电源保证。选定实物后重新核对峰值电流、线材与分配路径。
- 不通过开发板3V3或面包板细电源轨给多颗腿部舵机供电；按设计分配电源并共地。
- 多轴后，当前LED与舵机已使用不同LEDC定时器；ESP32-S3的LEDC通道有限。四足阶段再选择外部PWM模块或独立运动板，不预先假定所有关节都能直接分配LEDC通道。
- 小智为ESP-IDF工程，Sesame为Arduino工程；先分离验证运动，再做移植或双板通信集成。双板是备选，不是当前必须购买第二块板的理由。

## 当前下一步建议

先确定想要的外形、是否必须第一版就能走路、预算和打印条件，再固定结构与采购表。现有固件保留为可回退基线，研究代码不覆盖主工程。
