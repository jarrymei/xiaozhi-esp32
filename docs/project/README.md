## 开发方向

**当前有效决定（2026-10-26最新更新）**：转向原创外形与参数化机械结构，先测量现有硬件、验证机械样机，再设计插接现有ESP32开发板的扩展PCB。屏幕脸＋四舵机双足、暂不加手臂为待细化建议。下述成品主板与原版外壳选型保留为历史记录，不作为当前采购依据。

2026-10-26：Microduck 复刻调整为远期规划；近期开发桌面陪伴机器人，参考 EMO 的表情与互动体验，并研究四足蜘蛛式结构。继续使用现有 ESP32-S3 与小智工程。

同日更新：用户选择OTTO-EMO作为近期方向，四足不再作为当前主线。选定OttoRobot V1.1非摄像头电子路线与原版Verdure EMO外壳，先四舵机腿脚、后续再扩手臂。实际板号、屏幕和打印件需按采购清单配套核对。
