## 开发方向

**当前有效决定（2026-10-26最新更新）**：转向原创外形与参数化机械结构，先测量现有硬件、验证机械样机，再设计插接现有ESP32开发板的扩展PCB。屏幕脸＋四舵机双足、暂不加手臂为待细化建议。下述成品主板与原版外壳选型保留为历史记录，不作为当前采购依据。

2026-10-26：Microduck 复刻调整为远期规划；近期开发桌面陪伴机器人，参考 EMO 的表情与互动体验，并研究四足蜘蛛式结构。继续使用现有 ESP32-S3 与小智工程。

同日更新：用户选择OTTO-EMO作为近期方向，四足不再作为当前主线。选定OttoRobot V1.1非摄像头电子路线与原版Verdure EMO外壳，先四舵机腿脚、后续再扩手臂。实际板号、屏幕和打印件需按采购清单配套核对。

## 当前进展

2026-11-02补充：微雪1.69寸240×280 LCD已点亮，基础双眼动画已烧录；用户确认自动眨眼、聆听和说话时的表情切换正常。当前启动彩条已关闭。具体实现、验证范围与回退方法见[双眼表情实验](../experiments/04-robot-eyes/README.md)。

**当前下一步**：先优化LCD视觉与动画。现有效果比较简陋，先确定眼睛与信息布局的视觉稿，再调整眼形、动作节奏和情绪映射。四舵机接线板、联合动作和机械制作暂不推进；原创桌面机器人的长期方向不变。

截至 2026-10-26，已经完成：

- 面包板搭建小智 AI，烧录现成固件并完成语音对话。
- 搭建 ESP-IDF 环境，从源码编译、烧录并正常运行。
- 修改 BOOT 按键回调，显示屏幕提示、打印日志。
- GPIO 控制 LED 开关、LEDC PWM 调光，以及语音控制。
- 外部 5 V 供电驱动 SG90 舵机，完成角度控制。
- FreeRTOS 任务与队列控制循环摇头、停止动作。
- 打印云端 MCP 消息、工具名称、参数和舵机任务日志。
- 配置原生 USB JTAG 调试，解决软件断点写入失败问题后能够启动调试。

后续增加设备、更改接线或确认库存时，请同步更新清单。清单中的“待核对”不表示已经收到，也不表示缺货。
