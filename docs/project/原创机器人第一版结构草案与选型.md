# 原创机器人第一版结构草案与选型

> 后续进展：A0布局已获用户认可，已建立[A1参数化机械结构与装配模型](./mechanical/a1/README.md)。实际细化后脚距、关节高度、总外包和打印重量发生调整，以A1及其检查报告为准；下文保留布局阶段依据。

版本：A0，2026-10-26。交付范围：机构概念、占位布局、候选BOM、预算分配及供电/引脚预案。不是加工图，未完成干涉分析或承重实测，不能据此直接打印整机。

## 设计决定

首版采用四舵机双足、无膝关节、无手臂，开放式电子平台与可拆彩屏脸。继续复用现有44针ESP32-S3、INMP441、MAX98357与扬声器；旧SG90留作实验。用同规格的四颗位置舵机形成腿脚。目标为有线供电下语音、表情与短距离慢走。

预算上限300元，包含新增零件、试打、整套打印和运费。暂不制作扩展PCB、电池与充电电路、装饰耳机和完整封闭外壳。

结构示意见[正视与侧视草图](./references/原创机器人A0结构草图.svg)。全部整机尺寸是设计变量，不是实测值或兼容性结论。

## 四个关节怎样连接

以机器人自身左右命名：X向右，Y向前，Z向上。

| 关节 | 轴线 | 固定部分 | 旋转连接部分 | 作用 |
|---|---|---|---|---|
| 左/右腿关节，各1颗 | Z轴，竖直 | 舵机本体固定于机身底部，输出轴向下 | 配套摇臂固定到腿连接件 | 左右腿分别绕竖直方向转动，带动脚在水平面摆转 |
| 左/右脚关节，各1颗 | 局部Y轴，前后方向 | 舵机本体固定在随腿转动的腿连接件内 | 配套摇臂连接脚部侧板 | 让脚与腿相对侧倾，配合机身左右移重心 |

机身 → 腿舵机摇臂 → 腿连接件（携带脚舵机）→ 脚舵机摇臂 → 脚部侧板/脚底。前后轴随腿关节一起转动，并非全程固定在世界坐标Y方向。

这是摆转和侧倾配合的小步行走，不是有膝关节的人形迈腿。四轴需要协调周期、方向和零位，不能把当前单舵机摇头复制四份。Otto官方运动库包含四电机步态及校准示例，本地`main/boards/otto-robot/otto_movements.cc`也有相位协调实现；只借鉴运动原理，保留现有板级与音频配置。

摇臂优先使用舵机随附件，不打印花键。转动另一端可设置同轴被动支撑，孔位在实物试装后确定；不能用打印支架强行夹住输出轴。初版腿连接件需能拆卸和调整，保留摇臂中心螺丝的工具入口。

## A0占位尺寸与重量约束

| 参数 | 暂定值 | 说明 |
|---|---|---|
| 上部机身占位 | 宽86×深60×高60 mm | 开放式平台与立柱，不是实心盒；底面暂取离地62 mm |
| 整机最高点 | 约122 mm | 由布局推算，接插件和线缆可能增加高度 |
| 单脚底 | 宽44×长64 mm | 先按刚性薄底板加肋设计，防滑垫可更换 |
| 双脚中心距 | 60 mm | 中立时总宽104 mm、内侧间隙16 mm；活动时必须重新检查碰撞 |
| 腿关节中心距 | 50 mm | 腿连接件暂需每侧向外偏置5 mm，避免把轴线关系画成不可装配的直杆 |
| 腿/脚关节离地高度 | 约62 / 25 mm | 是轴线占位，不是舵机外壳高度；用实物摇臂偏移复核 |
| 整机质量目标 | 尽量≤220 g | 设计目标，尚未称重；超过250 g则先暂停整套打印并复核执行器与布局 |
| 打印件质量目标 | 约50～70 g | 仅为预算和轻量化目标，必须切片后获得实际值 |

把较重模块尽量放在机身下部、左右居中；扬声器避开腿部活动区，麦克风拾音孔外露，功放和舵机电源线避开麦克风。屏幕面板先单独拆装，USB出线向后且留松弛环，避免牵拉重心。不能把面包板整体背上机器人；用独立小模块与固定线束。

粗略静态筛查：若单脚支撑质量为0.22 kg，重心到相关轴的水平力臂假设3 cm，则重力矩约0.66 kgf·cm。该估算没有包含步态加速度、摩擦、齿隙和冲击，不能由此证明舵机够用；实际力臂与负载须从装配与运动状态确定。

## 候选配件与证据

### 舵机：MG90S级位置舵机×4，条件候选

[TowerPro厂家页面](https://towerpro.com.tw/product/mg90s-3/)列出13.4 g、22.8×12.2×28.5 mm、4.8 V时堵转扭矩1.8 kgf·cm。四颗按该标称共53.6 g。厂家表格与正文还有12.4/12.2 mm等口径差异，选定批次前不得把正文外形直接用作安装公差。

选它的理由是体积较小、金属齿轮、可使用随附摇臂；不是因为名称带“金属”就保证步行承重。厂家页面没有给出可用于本项目的完整电流曲线和连续扭矩，且提示同名仿品问题。因此该型号目前为尺寸和重量参考，没有确认国内具体SKU。

下单条件：明确为位置型（排除360°连续旋转），确认有效行程足够、5 V使用条件、3.3 V控制信号兼容性、孔距/轴心/摇臂图、配套螺丝、同批次供货。不能把不同商家的“MG90S”视作机械与性能完全一致。若可靠四颗报价超过预算，重新比较轻量化SG90级方案；不默默以低价仿品替代原厂参数。

### 彩屏：优先1.69寸ST7789V2无触摸模块

[微雪1.69寸官方产品页](https://www.waveshare.com/product/displays/lcd-oled/lcd-oled-3/1.69inch-lcd-module.htm)提供240×280、SPI、模块31.50×39.00 mm、显示区约27.97×32.63 mm、3.3/5 V模块供电说明及针序。无触摸版与触摸版尺寸不同，不能混用。选用独立CS、DC、RST、BL引脚的模块，避免首版引入触摸控制。

[中文官方分类页](https://www.waveshare.net/left_column/LCD-OLED.htm)检索时列出该模块49.49元，1.54寸模块52.52元；这是页面参考，不是含运费、优惠和库存确认的结算价。具体1.69寸商品页直接访问超时，尚未核实国内库存。

备选为[1.54寸ST7789官方模块](https://www.waveshare.com/product/displays/lcd-oled/1.54inch-lcd-module.htm)，240×240，模块50×35 mm，显示区27.72×27.72 mm。其1.54寸可视面积不会占满86 mm宽脸部：外壳宽度与屏幕可视宽度分开设计。若希望更大屏，需要重新比较尺寸、重量和预算。

本地其他板级存在ST7789 240×280配置，可借鉴显示驱动，不能直接切换到那个板型：其音频引脚与现有板不同。后续在现有板级增设SPI显示适配，验证颜色顺序、偏移、旋转与背光电路。

## 电源与信号预案

第一轮逻辑板由电脑USB供电，舵机由独立稳压5 V电源供电，共地；外部5 V不接开发板5V脚，避免在未知板卡电路上与电脑USB并接。腿部电源独立分配到四颗舵机，不经过开发板或面包板细电源轨。

为选型预留5 V、约4 A级电源能力，但这不是已证明四颗舵机足够的结论，也不是允许直接使用所有标称5 V电源。取得所选舵机启动/负载资料并实测压降后冻结容量、线径、连接器和保护。舵机正极支路设置能承受负载电流的断电开关；逻辑GND直接连接分配点，功率回流不串过麦克风地线。

现有充电器先看铭牌。屏幕优先按该模块允许的3.3 V电源与逻辑条件验证，背光按模块电路接，不把裸背光LED直接挂GPIO。开发板3V3剩余供电能力仍需核对。

以下只是候选资源表，未修改代码、不是立即改线通知；实施前逐项核对实物丝印及板卡原理图。

| 功能 | 候选GPIO/资源 |
|---|---|
| 四舵机 | 17、8、13、14；LEDC通道0、1、3、4共用50 Hz定时器3 |
| LED | 保留GPIO18，通道2、定时器2，不与腿脚混用 |
| LCD SPI | CLK9、MOSI10、DC11、CS12、RST21；背光控制候选GPIO1 |
| 麦克风/功放 | 保留4/5/6与7/15/16 |
| OLED | 41/42可保留台架调试；不作为最终脸部 |
| 下载调试 | 保留USB19/20、UART43/44、BOOT0；不使用35～37等可能涉及板载存储的脚 |

候选表沿用通道3只代表重新设计后的统一多轴控制，必须停用旧单舵机控制器对该通道的占用。背光先考虑数字开关；需要PWM时另行分配通道与频率，不能共用舵机50 Hz定时器。

## 打印与验证计划

打印材料候选PLA；壳壁、肋和打印方向待结构模型确定。先做一个舵机座和摇臂连接试片，设置不同间隙供实际配合选择，不靠商品图误差直接确定最终公差。传力螺丝长度、孔径、中心距与被动支撑均随所选舵机实物核对。

建模下一阶段必须完成：四个轴线与传力链、腿连接件偏置、脚旋转扫掠、线束活动空间、屏幕面框、关节装配顺序、螺丝工具入口、打印体积与重量。模型通过后只发局部试打，不把A0占位草图当STL成品。

建议首版慢走验收草案：在平整硬质地面、有线但不手扶的条件下，连续向前移动20 cm，重复3次，不倾倒、不重启，结束后检查舵机发热、紧固与线束。该门槛是待实测调整的项目建议，尚未向用户承诺性能；桌面运行与防跌落不在此测试覆盖范围内。
