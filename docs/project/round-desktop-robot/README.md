# 圆形桌面机器人

首版为 USB-C 有线供电的无舵机语音桌宠，支持联网对话、彩屏双眼和字幕，整机按方便装配和维修设计。现有开发板用于功能验证，成品主板采用拟贴装的 ESP32-S3 模组。

- [外壳与内部装配](./xiaohuan-sphere/README.md)记录球壳、托架、线束卡座、拆装模型和打印件。现版球壳按直径 90 mm、高 83 mm 做样件布局，装机接口待核对。
- [A0 主板](./sphere-mainboard/README.md)记录引脚、电源预算、器件选型和本地板框草图。正式原理图在嘉立创 EDA 工程「圆形桌宠主板_A0」。降压电源替换、外设接线、封装审查和严格 ERC 仍待完成。

下一步用已选件的尺寸图与实物核对屏幕、喇叭、USB 插拔和主板安装空间，再同步更新外壳和主板。
